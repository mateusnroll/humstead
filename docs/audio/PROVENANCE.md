# Bundled audio provenance

All 13 bundled recordings received human listening approval on October 3, 2026. Application code is MIT licensed; each recording is separately offered under CC0 1.0.

Original files and source-page snapshots are retained in the private Liftoff run evidence. Existing recordings were acquired September 21, 2026; Rain on Puddle was acquired October 3, 2026. Original, evidence and derivative hashes were rechecked during final selection. The public manifest records provenance without private filesystem paths. Automated decoding tests supplement the recorded human audition.
