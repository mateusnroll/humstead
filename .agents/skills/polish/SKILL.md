# Humstead polish

Read [WORKFLOW.md](../../../docs/WORKFLOW.md) and inspect the actual application. Establish a clean isolated starting HEAD and narrow user-approved visual scope. Inspect/edit/reinspect native typography, spacing, keyboard focus, accessibility and reduced motion. Keep the prototype uncommitted.

No new dependency, persistence, integration, entitlement or product behavior. Route those changes through spec. To retain a prototype, freeze its research, obtain required approval, and prove mapped tests red against the original baseline in an isolated worktree. Only implement accepts retained work. Do not commit or publish.
